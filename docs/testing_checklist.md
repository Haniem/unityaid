# Программа и чеклист испытаний UnityAid

## Backend

- Выполнить `go test ./...`.
- Проверить миграции на чистой базе.
- Проверить авторизацию: регистрация, вход, refresh, logout, смена пароля.
- Проверить rate limit на auth endpoint.
- Проверить CRUD организаций, мероприятий, задач, новостей и базы знаний.
- Проверить заявки на мероприятия и подтверждение часов.
- Проверить начисление достижений и баллов.
- Проверить отчеты аналитики.
- Проверить запись audit log для `POST`, `PUT`, `PATCH`, `DELETE`.
- Проверить генерацию и скачивание сертификата.
- Проверить публичную проверку сертификата по коду.
- Проверить загрузку изображений и отказ для невалидных MIME-типов.

## Frontend

- Выполнить `npm run build`.
- Проверить вход и переходы по основному меню.
- Проверить адаптивность основных страниц.
- Проверить создание, редактирование и удаление основных сущностей.
- Проверить страницу отчетов `/analytics`.
- Проверить уведомления в topbar и страницу `/notifications`.
- Проверить базу знаний.
- Проверить страницу сертификатов.
- Проверить вход в `/admin` из настроек супер-администратора.

## Ручной демонстрационный сценарий

1. Супер-администратор входит в систему.
2. Создает или открывает организацию.
3. Добавляет пользователя в организацию.
4. Создает мероприятие.
5. Волонтер подает заявку.
6. Координатор подтверждает заявку.
7. Координатор отмечает участие и часы.
8. Система начисляет баллы и достижения.
9. Координатор формирует сертификат.
10. Внешний проверяющий проверяет сертификат по коду.
11. Супер-администратор открывает аналитику и audit log.
12. Супер-администратор открывает админ-панель и проверяет сущности.
