# Руководство пользователя UnityAid

## Волонтер

1. Входит в систему по email и паролю.
2. Заполняет профиль: контакты, город, интересы, навыки.
3. Открывает мероприятия и подает заявку на участие.
4. Отслеживает статус заявки.
5. Участвует в мероприятии или выполняет задачу.
6. Вносит часы участия.
7. Получает достижения и баллы.
8. Открывает сертификаты и скачивает доступные документы.
9. Оставляет обратную связь после завершения мероприятия.
10. Читает новости и статьи базы знаний.

## Координатор

1. Создает мероприятия, задачи, новости и статьи базы знаний в доступных организациях.
2. Рассматривает заявки волонтеров.
3. Отмечает посещаемость и подтверждает часы.
4. Назначает задачи и контролирует выполнение.
5. Просматривает обратную связь участников.
6. Формирует сертификаты и справки для волонтеров.
7. Анализирует отчеты по доступному контенту.

## Администратор организации

1. Управляет данными организации.
2. Добавляет участников организации.
3. Назначает роли внутри организации.
4. Контролирует мероприятия, задачи, новости и волонтеров своей организации.

## Супер-администратор

1. Управляет системными ролями в настройках.
2. Открывает системную админ-панель из настроек.
3. Управляет всеми основными сущностями приложения.
4. Просматривает audit log и отчеты по действиям сотрудников.
