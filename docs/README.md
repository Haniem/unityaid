# Документация UnityAid

Документы разложены по папкам по назначению.

## `readme`

Файлы для быстрого понимания проекта и работы с системой:

- `launch_instructions.md` - как запустить проект;
- `user_guide.md` - сценарии пользователя;
- `admin_guide.md` - сценарии администратора.

## `codex`

Рабочие технические файлы, которые удобно использовать при разработке и дальнейших задачах:

- `implemented_functionality.md` - весь реализованный функционал по модулям;
- `api_overview.md` - краткий обзор API основного приложения;
- `control_plane_api.md` - API control plane;
- `er_diagram.md` - ER-диаграмма;
- `testing_checklist.md` - программа и чеклист испытаний.

## `roadmaps`

Планы развития:

- `development_roadmap.md` - исходная дорожная карта дипломного MVP;
- `saas_product_roadmap.md` - дорожная карта managed single-tenant SaaS.

## `product`

Продуктовые материалы:

- `product_strategy.md` - концепция превращения UnityAid в реальный продукт.

## `academic`

Учебные и дипломные материалы:

- техническое задание;
- переработанное ТЗ в Markdown.

## `archive`

Файлы-примеры и материалы, которые не являются актуальной рабочей документацией проекта.
