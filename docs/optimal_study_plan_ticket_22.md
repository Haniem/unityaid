# 1. Главный принцип

Тебе не нужно идеально выучить весь файл слово в слово. Тебе нужно:

1. Понимать логику каждого вопроса.
2. Помнить структуру ответа.
3. Уметь проговорить ответ своими словами.
4. Быстро восстанавливать детали: определения, сравнения, примеры, сложности алгоритмов.
5. Уметь отвечать на дополнительные вопросы.

Самая эффективная стратегия:

```text
короткое чтение -> закрыть файл -> воспроизвести вслух -> проверить -> исправить пробелы -> повторить через паузу
```

Это намного лучше, чем просто читать конспект несколько раз подряд.

# 2. Какие методы запоминания использовать

## 2.1. Активное воспроизведение

Активное воспроизведение - это когда ты закрываешь материал и пытаешься достать ответ из памяти.

Примеры:

- закрыть конспект и вслух объяснить RGB, CMYK и HSV;
- написать по памяти этапы юзабилити-тестирования;
- нарисовать таблицу сложностей сортировок без подсказки;
- ответить на вопрос так, будто уже стоишь перед комиссией.

Почему это работает:

Мозг лучше запоминает то, что он сам извлекает из памяти. Простое чтение создает ощущение знакомости, но на экзамене нужно не узнавать текст, а самостоятельно его воспроизводить.

## 2.2. Распределенное повторение

Распределенное повторение - это повторение материала через интервалы, а не одной длинной сессией подряд.

Для подготовки за один вечер интервалы будут короткими:

- первое изучение;
- повтор через 20-30 минут;
- повтор через 1-2 часа;
- финальное повторение перед сном;
- легкое повторение утром.

## 2.3. Пробный устный экзамен

Так как экзамен устный, учить нужно вслух.

Минимум 3 раза за вечер:

1. Проговорить весь билет по плану.
2. Засечь время.
3. Записать слабые места.
4. Исправить их по конспекту.

Важно:

Если ты можешь объяснить тему вслух без конспекта, значит ты действительно готов.

## 2.4. Самообъяснение

Самообъяснение - это когда ты не просто называешь факт, а объясняешь причину.

Плохо:

```text
CMYK используется в печати.
```

Хорошо:

```text
CMYK используется в печати, потому что печать работает с красками, которые поглощают часть света. Черный канал K добавляют, потому что смешение CMY не дает качественный черный цвет.
```

На экзамене за это любят: ты показываешь понимание, а не механическую зубрежку.

## 2.5. Метод "скелет -> мясо -> примеры"

Для каждого вопроса учи в три слоя:

1. **Скелет** - структура ответа.
2. **Мясо** - определения, свойства, этапы, сравнения.
3. **Примеры** - RGB(255, 0, 0), сценарий юзабилити-теста, массив `[5, 2, 4, 6, 1, 3]`.

Если времени мало, сначала выучи скелет. Даже если забудешь детали, структура спасет ответ.

## 2.6. Интерливинг

Интерливинг - это чередование тем.

Не учи 2 часа только цветовые модели. Лучше:

```text
цветовые модели -> юзабилити -> сортировки -> снова цветовые модели -> снова юзабилити
```

Так мозг учится отличать темы друг от друга и быстрее переключаться, как на реальном экзамене.

## 2.7. Двойное кодирование

Двойное кодирование - это сочетание слов и визуальных схем.

Для этого билета нужны 3 простые схемы:

1. RGB: свет, сложение, экран.
2. CMYK: краска, вычитание, печать.
3. Сортировки: таблица сложностей.

Рисовать красиво не нужно. Главное - быстро восстановить логику.

## 2.8. Мнемоника

Мнемоника нужна для списков.

Этапы юзабилити-тестирования:

```text
ЦАСПУМПАОИП
```

Расшифровка:

```text
Ц - цель
А - аудитория
С - сценарии
П - прототип
У - участники
М - материалы
П - проведение
А - анализ
О - отчет
И - исправления
П - повторный тест
```

Можно запомнить фразой:

```text
Цель, аудитория, сценарии, прототип; участники, материалы, проведение; анализ, отчет, исправления, повтор.
```

Для сортировок:

```text
ВВO
```

```text
Вставками - вставляем.
Выбором - выбираем минимум.
Обменом - меняем соседей.
```

Для RGB/CMYK:

```text
RGB светит, CMYK печатает.
```

## 2.9. Метод Фейнмана

Объясни каждый вопрос так, будто рассказываешь человеку, который вообще не знает тему.

Если застрял - значит место слабое. Вернись в конспект и упрости объяснение.

## 2.10. Что почти не использовать

Не делай ставку на:

- многоразовое пассивное перечитывание;
- переписывание больших кусков конспекта;
- выделение цветом всего подряд;
- попытку выучить текст дословно;
- ночную зубрежку без сна.

Эти методы дают ощущение работы, но хуже готовят к устному воспроизведению.

# 4. Первый круг: понять и собрать скелет

## Блок 1. Вопрос 1: графика и цветовые модели - 35 минут

Цель: понять логику и запомнить структуру.

Что делать:

1. Прочитай раздел 1 из `exam_ticket_22.md`.
2. На листе выпиши только скелет:

```text
1. Графическое изображение
2. Растровая графика
3. Векторная графика
4. Цветовая модель
5. Аддитивная модель
6. RGB
7. Субтрактивная модель
8. CMY
9. CMYK
10. HSV
11. Сравнение RGB и CMYK
```

3. Закрой конспект.
4. Вслух объясни по этому скелету весь вопрос за 5-7 минут.
5. Открой конспект и отметь, что забыл.

Что обязательно запомнить:

- растровая графика = пиксели;
- векторная графика = математические объекты;
- RGB = аддитивная модель, экраны, свет;
- CMY/CMYK = субтрактивные модели, печать, краски;
- CMYK нужен из-за отдельного черного канала;
- HSV удобна для человеческого восприятия: тон, насыщенность, яркость.

Минимальный ответ, который должен сидеть в голове:

```text
RGB - свет и экраны. CMYK - краска и печать. HSV - удобное описание цвета через тон, насыщенность и яркость.
```

## Перерыв - 7 минут

Встань, вода, окно, никакого конспекта.

## Блок 2. Вопрос 2: юзабилити - 35 минут

Цель: запомнить определение и этапы.

Что делать:

1. Прочитай раздел 2 из `exam_ticket_22.md`.
2. Выпиши на лист этапы тестирования:

```text
цель -> аудитория -> сценарии -> прототип -> участники -> материалы -> проведение -> анализ -> отчет -> исправления -> повторный тест
```

3. Закрой конспект.
4. Вслух объясни:

```text
Что такое юзабилити?
Зачем нужно юзабилити-тестирование?
Какие этапы оно проходит?
Какие метрики используются?
```

5. Проверь себя по конспекту.

Что обязательно запомнить:

- юзабилити = удобство, понятность и эффективность использования;
- тестируют интерфейс, а не пользователя;
- задание должно описывать цель, а не подсказывать кнопки;
- этапы тестирования;
- метрики: успешность, время, ошибки, клики, удовлетворенность.

Минимальный ответ:

```text
Юзабилити - насколько удобно пользователю достигать цели. Юзабилити-тестирование - наблюдение за реальными пользователями, которые выполняют типичные задачи в WEB-приложении.
```

## Перерыв - 7 минут

## Блок 3. Вопрос 3: сортировки - 40 минут

Цель: запомнить идеи, свойства и сложности.

Что делать:

1. Прочитай раздел 3 из `exam_ticket_22.md`.
2. Выпиши таблицу по памяти, затем проверь:

```text
Вставками:
идея - вставляем элемент в отсортированную часть
лучший - O(n)
средний/худший - O(n^2)
память - O(1)
устойчивая - да
адаптивная - да

Выбором:
идея - выбираем минимум
лучший/средний/худший - O(n^2)
память - O(1)
устойчивая - обычно нет
адаптивная - нет

Обменом:
идея - меняем соседние элементы
лучший - O(n) с оптимизацией
средний/худший - O(n^2)
память - O(1)
устойчивая - да
```

3. Закрой конспект.
4. На массиве `[5, 2, 4, 6, 1, 3]` вслух объясни каждый алгоритм.
5. Не пытайся помнить каждую перестановку. Помни принцип.

Что обязательно запомнить:

- вставками - как карты в руке;
- выбором - ищем минимум;
- обменом - сравниваем соседей;
- все три простые сортировки в среднем `O(n^2)`;
- вставками лучше для почти отсортированных массивов;
- выбором делает мало обменов;
- пузырьковая в основном учебная.

- дать определение по каждому вопросу;

Что нельзя делать утром:

- читать весь конспект с нуля;
- панически искать новые материалы;
- пытаться выучить редкие детали;
- сравнивать себя с другими перед аудиторией.

# 13. Как отвечать на самом экзамене

## Перед ответом

# 15. Самые важные формулы памяти для этого билета

## Цветовые модели

```text
RGB = Red + Green + Blue = свет = экран = аддитивная
CMY = Cyan + Magenta + Yellow = краски = печать = субтрактивная
CMYK = CMY + Key/Black = качественный черный
HSV = Hue + Saturation + Value = удобно человеку
```

## Юзабилити

```text
Юзабилити = удобно + понятно + эффективно
Тестирование = реальные пользователи + типичные задачи + наблюдение
Этапы = цель -> аудитория -> сценарии -> прототип -> участники -> материалы -> проведение -> анализ -> отчет -> исправления -> повтор
```

## Сортировки

```text
Вставками = вставляем в отсортированную часть
Выбором = выбираем минимум
Обменом = меняем соседей
Все в среднем O(n^2)
Память у всех O(1)
```

# 16. На чем основан план

План опирается на методы, которые чаще всего подтверждаются исследованиями обучения:

- **practice testing / retrieval practice** - самопроверка и активное воспроизведение;
- **distributed practice / spaced repetition** - распределение повторов во времени;
- **interleaved practice** - чередование тем;
- **self-explanation** - объяснение причин и связей;
- **dual coding** - сочетание текста и схем;
- **concrete examples** - конкретные примеры вместо абстрактных фраз.

В обзоре Dunlosky et al. наиболее полезными для широкого круга студентов названы practice testing и distributed practice. Carnegie Mellon Eberly Center также описывает retrieval practice как способ укреплять память и перенос знания в новые ситуации. Обзор по evidence-based learning strategies выделяет spaced practice, interleaving, retrieval practice, elaboration, dual coding и concrete examples.

Источники:

- [Dunlosky et al., Improving Students' Learning With Effective Learning Techniques, PubMed](https://pubmed.ncbi.nlm.nih.gov/26173288/)
- [Dunlosky et al., full text, Sage Journals](https://journals.sagepub.com/stoken/rbtfl/Z10jaVH/60XQM/full)
- [Carnegie Mellon Eberly Center: Retrieval Practice](https://www.cmu.edu/teaching/resources/instructionalstrategies/activelearningstrategies/retrievalpractice/index.html)
- [Using Evidence-Based Learning Strategies to Improve Medical Education, PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC10368606/)
