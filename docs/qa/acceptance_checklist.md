# Приемочный чеклист UnityAid

## Волонтер

- [ ] Регистрация или вход по приглашению доступны.
- [ ] Профиль волонтера редактируется.
- [ ] Заявка на мероприятие создается один раз и не перезаписывается повторно.
- [ ] После завершения мероприятия часы отображаются корректно.
- [ ] Сертификат открывается и проверяется по коду.

## Координатор

- [ ] Мероприятие создается вручную.
- [ ] Мероприятие создается из шаблона.
- [ ] Серия повторяющихся мероприятий создается корректно.
- [ ] Массовое подтверждение и отклонение заявок работают.
- [ ] Массовая посещаемость отмечает выбранных участников.
- [ ] Повторное завершение мероприятия не начисляет часы второй раз.

## Руководитель

- [ ] Executive dashboard открывается.
- [ ] Управленческий, грантовый, филиальный и координаторский отчеты открываются.
- [ ] Отчет проблемных зон показывает ожидающие действия.
- [ ] Фильтры отчетов сохраняются и применяются.
- [ ] XLSX и PDF выгрузки запускаются.

## Надежность

- [ ] Основные страницы имеют empty/loading/error states.
- [ ] Даты отображаются в локальном часовом поясе пользователя.
- [ ] Аудит фиксирует действия с ролями, часами, сертификатами и экспортами.
- [ ] Сборка фронтенда проходит.
- [ ] Тесты backend проходят.
