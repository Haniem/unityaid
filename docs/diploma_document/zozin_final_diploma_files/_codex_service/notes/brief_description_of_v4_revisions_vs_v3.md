# Доработки версии V4 пояснительной записки «Пульс» относительно V3

Версия V4 подготовлена после реализации дополнительного функционала приложения и содержит только подтвержденные изменения.

## Что реализовано в приложении

- Добавлен workflow GitHub Actions `.github/workflows/quality.yml` с проверками backend (`go vet`, `go test`, `go build`), frontend (`npm run build`) и контейнерным smoke-сценарием.
- Переработан профиль волонтера: вкладки «Личная информация», «Задачи», «Работа», «Мероприятия», «Достижения и документы».
- Добавлена загрузка аватара через проверяемый endpoint `/api/v1/files/profile-avatars`.
- Реализована настройка профиля администратором: системные защищенные группы, пользовательские группы и поля, типы данных, обязательность, активность и варианты выбора.
- В БД добавлены таблицы `profile_field_groups`, `profile_field_definitions`, `profile_field_options`, `profile_field_values` и миграция `020_profile_fields.sql`.

## Что дополнено в пояснительной записке

- Во вторую главу включено описание расширенного профиля, модели хранения настраиваемых полей, разграничения доступа и CI/CD.
- Добавлены реальные экранные снимки конструктора полей и вкладки профиля с сохраненным пользовательским значением.
- В третьей главе зафиксированы фактически выполненные проверки нового функционала: применение миграции, создание группы и поля, сохранение значения, отклонение удаления системного поля с HTTP 409 и загрузка изображения аватара.
- В приложение экранных форм добавлены рисунки Д.9 и Д.10; в доказательные материалы включен листинг workflow GitHub Actions.

## Фактически выполненные проверки

- `go test ./...` - успешно, при этом backend пока не содержит тестовых файлов (`[no test files]`).
- `go vet ./...` - успешно.
- `go build ./...` - успешно.
- `npm run build` - успешно.
- `docker compose config --quiet` - успешно.
- Сценарий API расширенного профиля на запущенном backend/PostgreSQL - успешно.
- Визуальная проверка экранов администрирования полей и вкладки «Работа» профиля - успешно.

## Ограничения

- В существующей локальной демонстрационной базе первоначальный email суперадминистратора сохранен как `admin@unityaid.test`, поскольку seed был применен до ребрендинга. На чистом развертывании актуальные seed-файлы создают `admin@puls.test`.
- `go test ./...` проверяет компилируемость пакетов; полноценные unit/integration tests остаются следующим этапом развития.
