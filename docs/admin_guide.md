# Руководство администратора UnityAid

## Доступ

Системная админ-панель доступна по маршруту `/admin`. Ссылка отображается в настройках только пользователю с ролью `super_admin`.

## Возможности

- Просмотр разрешенных сущностей.
- Постраничная навигация.
- Поиск по настроенным полям.
- Создание записей через JSON-форму.
- Редактирование записей через JSON-форму.
- Удаление записей там, где это разрешено.
- Просмотр audit log без ручного изменения.

## Управление пользователями

При создании пользователя через админ-панель можно передать `email`, `first_name`, `last_name`, `patronymic`, `avatar_url`, `locale`, `is_active`, `is_email_verified`.

Если `password_hash` не передан, backend назначает временный пароль `ChangeMe123!`. После этого пользователю нужно сменить пароль.

## Осторожность

Админ-панель работает с низкоуровневыми сущностями. Перед удалением записей нужно проверить связанные данные: мероприятия, задачи, часы, заявки и сертификаты.

Критичный журнал `audit_log` доступен только для чтения.
