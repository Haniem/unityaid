# Панель руководителя UnityAid

## Цель

Показать руководителю организации коммерческую и операционную ценность волонтерской программы: сколько людей вовлечено, сколько часов подтверждено, какие мероприятия и задачи дают результат, где есть проблемы.

## Первый экран

- активные волонтеры за период;
- подтвержденные часы;
- проведенные мероприятия;
- закрытые задачи;
- выданные сертификаты;
- доля неподтвержденных часов;
- статус последнего backup и deploy для managed-поставки.

## Отчеты

- отчет для руководства: краткая сводка по KPI и динамике;
- отчет для грантодателя: часы, мероприятия, участники, сертификаты;
- отчет по филиалам и организациям;
- отчет по сотрудникам и координаторам;
- отчет по проблемным зонам: просроченные задачи, неподтвержденные часы, низкая посещаемость.

## Экспорт

- PDF summary для руководства;
- XLSX/CSV для аналитиков;
- JSON archive для интеграций и миграции.

## Метрики эффективности

- среднее число часов на активного волонтера;
- конверсия заявок в посещения;
- доля мероприятий с QR-check-in;
- среднее время подтверждения часов;
- число ручных правок после полевого учета;
- активность координаторов.
